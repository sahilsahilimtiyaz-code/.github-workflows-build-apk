## 2024-10-13 - Zustand Selector Pattern
**Learning:** The React frontend heavily relies on Zustand for global state (`useCartStore`). Components were destructuring the entire store (`const { items, addItem } = useCartStore();`), which is an anti-pattern that causes components to unnecessarily re-render (O(N) rendering problem) whenever *any* state in the store changes, even if they only need a single method.
**Action:** Always use specific selector functions (e.g., `const items = useCartStore((state) => state.items);`) when accessing Zustand stores in this codebase to prevent unnecessary re-renders and maintain optimal performance.
