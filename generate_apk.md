# Mobile Application Conversion

We have provided a script `generate_apk.sh` to convert the Claude web application into a mobile application using Apache Cordova.

To generate the APK at any point, run the script:
```bash
./generate_apk.sh
```

Ensure you have `npm` and a valid Android SDK + JDK installation before running the script. The script will install Cordova globally if it is not already installed.
